# Filtro

Filtro is an image processing application that transforms regular photos into visual artworks inspired by the **Pop Art style of Andy Warhol**.

The goal of the project is to provide a simple and fast tool for applying colorful, high-contrast artistic effects to create unique portraits.

## ✨ Features

* 🖼️ Image import
* 🎨 Pop Art effects inspired by Andy Warhol
* 🌈 Generation of vibrant color palettes
* ⚡ Fast image processing
* 🖥️ Simple and intuitive interface
* 🌐 Browser-based application

## 📦 Local Installation

### Prerequisites

* Python 3.x
* Git

### Clone the repository

```bash
git clone https://github.com/Alexandre-git-SDV/Filtro.git
cd Filtro
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```

The application will then be available locally depending on your server configuration.
