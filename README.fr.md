# Filtro

Filtro est une application de traitement d’image qui transforme des photos classiques en œuvres visuelles inspirées du style **Pop Art d’Andy Warhol**.

L’objectif du projet est de proposer un outil simple et rapide permettant d’appliquer des effets graphiques colorés, contrastés et artistiques afin de créer des portraits uniques.

## ✨ Fonctionnalités

* 🖼️ Importation d’images
* 🎨 Application d’effets Pop Art inspirés d’Andy Warhol
* 🌈 Génération de palettes de couleurs vives
* ⚡ Traitement rapide des images
* 🖥️ Interface simple et intuitive
* 🌐 Application accessible depuis un navigateur

## 📦 Installation locale

### Prérequis

* Python 3.x
* Git

### Cloner le projet

```bash
git clone https://github.com/Alexandre-git-SDV/Filtro.git
cd Filtro
```

### Installer les dépendances

```bash
pip install -r requirements.txt
```

### Lancer l’application

```bash
python app.py
```

L’application sera ensuite disponible localement selon la configuration du serveur.
